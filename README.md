# jump-to-location

A simple webpage that allows you to link to a function or class in your source
code without using a line number that could change. Searches the file and then
redirects the user to your source code.

Example:

[https://jpiland16.github.io/jump-to-location?repo=jpiland16/optics-web&file=eye/navarro-eye.js&type=js-class&jump=NavarroEye](https://jpiland16.github.io/jump-to-location?repo=jpiland16/optics-web&file=eye/navarro-eye.js&type=js-class&jump=NavarroEye)
